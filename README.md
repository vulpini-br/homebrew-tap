# Homebrew tap for Quadra

[Quadra](https://github.com/ahrmichelon/quadra) arranges your Mac's windows on a grid.

```bash
brew install --cask ahrmichelon/tap/quadra
```

Update with `brew upgrade --cask quadra`.

The cask in `Casks/quadra.rb` is updated automatically each time a new Quadra version is
released. Problems with Quadra itself go to the
[Quadra issues](https://github.com/ahrmichelon/quadra/issues).
